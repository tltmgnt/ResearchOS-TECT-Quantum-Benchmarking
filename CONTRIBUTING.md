# Contributing

Run `python -m unittest discover -s tests -v` and the README example workflow. Document changes to gates, bit order, random sampling and resource formulas; include independent known-answer or boundary checks. Preserve missing-data behavior and the distinction between ideal simulation, declared observations and measured hardware results.

New estimators need explicit equations, parameter domains, compiler/architecture assumptions, timing scope, uncertainty and reference benchmarks. Do not label declared runtime ratios as measured speedup. Do not renew or alter evidence hashes to conceal failed integrity checks. Keep secrets and unpublished partner data out of this public repository. Submit focused pull requests with behavior and verification evidence.
