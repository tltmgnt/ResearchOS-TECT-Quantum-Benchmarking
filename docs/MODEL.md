# Models and practical limits

## Ideal simulator

A circuit starts in the all-zero computational basis state. H applies the normalized Hadamard matrix; X exchanges target amplitudes; Z changes the sign of the target-one amplitudes; CX exchanges target pairs only when the control bit is one. Probabilities are squared amplitude magnitudes, normalized after gate application to remove floating-point drift.

Qubit 0 is the least significant bit. Displayed strings read `q[n-1]...q0`. For example, X on qubit 2 in a three-qubit register produces `100`. Bell and GHZ distributions, H-Z-H phase interference, inverse H pairs, and reversed CX control ordering are checked in tests.

Limits: 1–12 qubits, at most 10,000 gates, no more than 20 million state-amplitude gate operations, and 1–1,000,000 shots. No mid-circuit measurement, reset, nonunitary operation, arbitrary rotations or noise channel is supported. This is a classically tractable correctness fixture, not a large-algorithm performance benchmark.

Finite-shot sampling uses a local `random.Random(seed)` instance and sorted bitstrings, with no global random state. The manifest records Python version. Seeded samples are reproducible for the same implementation/runtime; cross-version floating-point or random implementation changes may affect boundary cases. Re-verification uses exact JSON equality under the current runner and may reject a bundle generated by different numerical behavior. Preserve the runner revision and Python environment with important studies.

TVD is `0.5 × sum(|p(k) − q(k)|)` over the union of outcomes. Expected probabilities are owner-supplied and must sum to one. TVD against a finite count distribution is an empirical point estimate; no confidence interval, hypothesis test, or uncertainty propagation is implemented. A quality pass uses the owner-defined TVD threshold; it is not a scientific certification.

## Resource accounting

This is explicitly user-assumed arithmetic, not a fault-tolerant compiler. Resource logical depth and qubit count refer to the intended resource workload and are not inferred from the small demonstration circuit. The owner must establish that those assumptions describe the same workload as the baseline. Resource logical qubit count cannot be less than the benchmark register size.

- Physical qubits = logical qubits × physical qubits per logical + factory physical qubits.
- Cycles per shot = logical depth × cycles per layer.
- Estimated quantum time = cycles per shot × cycle time in microseconds × 10⁻⁶ × shots.
- Estimated total workflow time = classical preprocessing + estimated quantum time + classical postprocessing.
- Logical-qubit-cycle locations across all shots = logical qubits × cycles per shot × shots.
- Conditional failure union bound = min(1, locations × declared logical error per qubit-cycle).

Shots are sequential, with no parallelism, retries, queueing or stochastic stopping. Pre/postprocessing values are totals for the entire study, not per-shot values. Routing, memory overhead outside supplied assumptions, decoding, factory throughput, magic-state scheduling, control and cryogenic infrastructure are omitted. The failure expression is an upper bound only if the declared per-location value is a valid upper bound for all modeled events. It does not require independence, does not include unmodeled errors and is not a prediction of application success. No relation between physical error rate, code distance and logical error rate is modeled.

## Runtime comparison

The optional ratio is declared classical baseline seconds divided by estimated total quantum workflow seconds. It is emitted only if the record owner asserts the same problem and quality, the classical TVD meets the threshold, and the observed TVD (when supplied) or sampled TVD meets the threshold. Otherwise comparison is `not-comparable`; absent baseline or resources yields `no-data`.

This gate checks declarations, not their truth. The baseline must cover the same instance, workload count, output tolerance and end-to-end timing scope. No solver is run or timed. A synthetic observation remains synthetic even when its quality criterion passes. Timings in the example are fictional. The ratio is never evidence of measured quantum speedup or economic utility.

## Evidence and integrity

Experimental counts need evidence references; hashes verify bytes and links, not acquisition quality. The bundle captures the exact bytes read and checked. Output directories cannot be overwritten by the runner, but external edits remain possible. Anyone able to replace all inputs and hashes can forge a consistent bundle. Independent provenance review, signatures or protected storage are separate requirements when applicable.
